## 目标
- 在箱子详情页实现“袋子批量移动”功能（按钮位于 packageStorage/pages/box-detail/box-detail.wxml:112-117）。
- 交互流程与袋子详情页的“物品批量移动”一致，唯一差异：只展示两层选择（位置、箱子），不展示第三层袋子。
- 严格复用现有样式与交互范式，进度与结果弹窗保持一致。

## 影响范围
- 页面：`packageStorage/pages/box-detail/box-detail.wxml`、`box-detail.js`、`box-detail.wxss`
- 参考实现：`packageStorage/pages/bag-detail/bag-detail.wxml` 与 `bag-detail.js` 的批量模式、位置选择器、顺序移动逻辑

## 界面改动
1. 列表项支持“批量选择”遮罩
- 在袋子列表每个 `bag-item` 中添加与 `bag-detail` 一致的选中遮罩层与勾选图标（参考 bag-detail.wxml 的 `selection-overlay` 与 `cuIcon-roundcheckfill`）。
- 批量模式下点击袋子卡片切换选择；非批量模式保持现状（进入袋子详情/菜单）。

2. 批量工具栏
- 批量模式下在“袋子列表”上方显示工具栏（类名复用 `batch-toolbar`）：
  - 左侧显示“已选 N”。
  - 右侧提供两个按钮：`全选/全不选`、`选择目标位置`（打开两层选择器）。

3. 两层位置选择器弹窗
- 新增弹层结构，复用 `bag-detail` 的 `location-picker-modal` 视觉样式：
  - 第一列“位置”：来源于首页 `v0/home/info` 的盒子位置集合。
  - 第二列“收纳盒”：依据选中的位置过滤盒子列表；选择后仅记录目标 `box_id`。
  - 底部“确认移动到此处”按钮，点击后启动批量顺序移动。

4. 进度与结果弹窗
- 复用 `bag-detail` 的 `progress-modal` 与 `result-modal` 样式与结构，实时显示批量移动进度与结果汇总。

## 数据与状态
在 `box-detail.js` 的 `data` 中新增：
- 批量模式：`batchModeBags: boolean`、`selectedBagIds: number[]`、`selectAllChecked: boolean`
- 位置选择器：`showMovePicker: boolean`、`storageOptions: { locations: string[], boxes: any[] }`、`filteredBoxes: any[]`、`selectedLocation: string`、`selectedBox: any`
- 进度与结果：`movingProgress: { total, processed, success, skipped, failed, percent, running }`、`showResultModal: boolean`、`resultSummary: { success, skipped, failed }`

## 事件与方法
在 `box-detail.js` 新增并对齐命名与结构：
- 入口：`onBatchMove()` 开启批量模式并重置选择（参考 bag-detail.js:541-547）。
- 退出：`onExitBatchMode()` 关闭批量模式并清空选择（参考 bag-detail.js:554-559）。
- 切换选中：`onBagItemTap(e)` 在批量模式下转发到 `onToggleBagSelect(e)`；非批量模式保持 `onBagTap` 与 `onBagMenu`。
- 单项选择：`onToggleBagSelect(e)` 维护 `selectedBagIds` 与 `selectAllChecked`。
- 全选：`onToggleSelectAll()` 在全选与清空之间切换。
- 打开选择器：`onOpenMovePicker()` 校验已选袋子后加载位置与盒子；与 `bag-detail.js:onOpenLocationPicker` 同构，但不加载袋子。
- 关闭选择器：`onHideMovePicker()`。
- 加载位置与盒子：`loadStorageOptions()` 与 `requestHomeInfo(baseUrl, openid)`，解析 `v0/home/info` 生成 `locations` 与规范化 `boxes`。
- 选择位置：`onSelectLocation(e)` 依据位置过滤 `filteredBoxes` 并重置选中。
- 选择盒子：`onSelectBox(e)` 记录目标盒子。
- 确认目标：`onConfirmTargetBox()` 关闭弹层并调用批量顺序移动。
- 批量移动：
  - 单次移动封装 `moveBagToServer(data, baseUrl)`：`POST v2/bag/edit`，数据含 `openid`, `bag_id`, `box_id`。
  - 顺序执行 `startSequentialBagMove(targetBoxId)`：遍历 `selectedBagIds`，若目标与当前 `this.boxId` 一致则计为跳过，否则调用 `moveBagToServer` 并更新进度，完成后展示结果弹窗并 `loadBags()` 刷新列表，再 `onExitBatchMode()`。
- 关闭结果弹窗：`onCloseResultModal()`。

## 接口与数据来源
- 位置与盒子来源：`GET v0/home/info`（已有封装，参考 bag-detail.js:672-689）。
- 袋子列表刷新：`GET v2/bag/get`（已在 `box-detail.js:322-346`）。
- 批量移动调用：`POST v2/bag/edit`（后端模型已确认支持 `box_id`，参考 add-bag 页封装）。

## 边界与一致性
- 无袋子时点击“批量移动”直接提示；有袋子但未选择任何项时提示“请先选择袋子”。
- 仅显示两层选择；不加载第三层袋子列表。
- 样式与动效完全复用 `bag-detail` 的类名与设计语言，保持视觉一致性。
- 进度统计与结果汇总字段与表现与 `bag-detail` 相同。

## 验证方案
- 在当前箱子页勾选多个袋子，选择不同位置与盒子后执行移动：
  - 观察进度条与成功/跳过/失败统计是否正确更新；
  - 完成后袋子从当前列表消失（`loadBags()` 刷新），并能在目标盒的袋子列表中看到（通过切页验证）。
- 验证重复移动（目标与当前一致）被计入“跳过”。
- 验证接口异常时失败计数与提示。
